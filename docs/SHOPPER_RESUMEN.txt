----------------------------------------------------------------
  ENDPOINTS COMPLETOS BACKEND
----------------------------------------------------------------

AUTH:
  POST   /auth/register              → Crear cuenta
  POST   /auth/login                 → Iniciar sesión
  POST   /auth/refresh               → Renovar tokens
  POST   /auth/logout                → Cerrar sesión
  PATCH  /auth/change-password       → Cambiar contraseña [NUEVO]

USERS:
  PATCH  /users/me                   → Editar nombre propio [NUEVO]
  GET    /users                      → Listar todos (admin)
  PATCH  /users/:id/role             → Cambiar rol (admin)
  DELETE /users/:id                  → Desactivar cuenta (admin)

STORES:
  GET    /stores                     → Listar tiendas
  POST   /stores                     → Crear tienda (admin)
  GET    /stores/my                  → Mis tiendas (owner)
  GET    /stores/:id                 → Ver tienda
  PATCH  /stores/:id                 → Editar tienda
  DELETE /stores/:id                 → Eliminar tienda

PRODUCTS:
  GET    /stores/:storeId/products         → Listar productos
  POST   /stores/:storeId/products         → Crear producto (owner)
  GET    /stores/:storeId/products/:id     → Ver producto
  PATCH  /stores/:storeId/products/:id     → Editar producto
  DELETE /stores/:storeId/products/:id     → Eliminar producto

CART (Redis):
  GET    /cart                       → Ver carrito
  POST   /cart/items                 → Agregar item
  PATCH  /cart/items/:productId      → Actualizar cantidad
  DELETE /cart/items/:productId      → Eliminar item
  DELETE /cart                       → Vaciar carrito

ORDERS:
  POST   /orders/checkout            → Crear orden desde carrito
  GET    /orders                     → Todas las órdenes (admin)
  GET    /orders/my                  → Mis órdenes (buyer)
  GET    /orders/store/:storeId      → Órdenes de una tienda (owner)
  GET    /orders/:id                 → Ver detalle de orden
  PATCH  /orders/:id/status          → Cambiar estado (admin)

UPLOAD:
  POST   /upload/image?folder=stores → Subir imagen a Cloudinary
  POST   /upload/image?folder=products

================================================================
  5. SISTEMA DE ROLES
================================================================

  super_admin → Acceso total a toda la plataforma
  admin       → Gestiona tiendas y usuarios
  owner       → Gestiona su propia tienda y productos
  buyer       → Comprador, acceso al portal público

  El middleware protege rutas automáticamente leyendo el rol
  desde el JWT guardado en cookie (no en localStorage, ya que
  el middleware de Next.js no tiene acceso a localStorage).


================================================================
  6. FLUJO DE AUTENTICACIÓN
================================================================

  1. Usuario hace login → backend devuelve accessToken (15min)
                          y refreshToken (7 días)
  2. auth.store.ts guarda tokens en localStorage y cookie
  3. api.ts adjunta Bearer token en cada request
  4. Si el request devuelve 401, el interceptor hace refresh
     automáticamente con el refreshToken
  5. Si el refresh falla → logout automático → /auth/login
  6. Middleware Next.js lee cookie "accessToken" para proteger
     rutas server-side antes de renderizar
