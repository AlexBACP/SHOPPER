  9. PRINCIPIOS DE DISEÑO APLICADOS
================================================================

  1. TEXTO SOBRE DORADO = OSCURO (#09090b, nunca blanco)
     El ámbar es un color claro, no soporta texto blanco.

  2. SOMBRAS EN TONO DORADO = shadow-amber-900/40
     Las sombras azules (shadow-blue-900/30) eran del tema anterior.

  3. BOTONES PRIMARIOS = btn-shimmer + bg-accent + text-[#09090b]
     Efecto de barrido de luz al hacer hover.

  4. GRADIENTES DE TEXTO = clase .texto-dorado
     No usar inline styles — usar la clase utilitaria.

  5. UN SOLO NAVBAR = el global en layout.tsx
     Ninguna página debe tener su propio <nav> duplicado.

  6. FOOTER GLOBAL = en layout.tsx después de <main>
     Ninguna página debe incluir su propio footer.

  7. FONDO ESTÁNDAR = .fondo-mesh o bg-[var(--bg)]
     Las páginas principales usan .fondo-mesh para el efecto premium.
